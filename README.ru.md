# Страница вопросов для Claude Code

[English](README.md) | Русский

Когда Claude нужно, чтобы ты решил несколько вещей (открытые моменты фичи, варианты реализации, уточнения), он обычно пишет их нумерованным списком. Ты отвечаешь «1 — да, 3 — потом» и теряешь связь: какой ответ к какому вопросу и что Claude на него сказал.

Этот мод выносит вопросы на страницу в браузере, которую держит хаб [webhub](https://github.com/jabenb/claude-webhub). Claude выкладывает их туда, ты отвечаешь на каждый в своём поле или готовым вариантом, а страница отправляет все ответы в сессию одним сообщением, каждый под своим вопросом. Claude отвечает на каждый ответ, и его реплика появляется под этим вопросом с отметкой «решён» или «ещё открыт».

## Установка

Страница живёт в хабе webhub, поэтому моду нужен мод `webhub`. Сначала поставь его, потом этот:

```
/plugin install webhub --marketplace jabenb/claude-webhub
/plugin install questions --marketplace jabenb/claude-questions-pane
```

Ответь `y`, чтобы добавить маркетплейс, затем выбери scope (см. ниже).

Из shell:

```bash
claude plugin install webhub --marketplace jabenb/claude-webhub
claude plugin install questions --marketplace jabenb/claude-questions-pane
```

В десктоп-приложении Claude: нажми **+** рядом с полем ввода, затем **Plugins**, **Add marketplace** с `jabenb/claude-webhub` и добавь **webhub**, затем так же `jabenb/claude-questions-pane` и **questions**.

### Глобально или в один проект

Scope определяет, где работает мод:

| Scope | Где работает | Куда записывается |
|---|---|---|
| `user` (по умолчанию) | во всех проектах | `~/.claude/settings.json` |
| `project` | в этом репозитории, у всех, кто его клонирует | `<проект>/.claude/settings.json`, коммитится |
| `local` | в этом репозитории, только у тебя | `<проект>/.claude/settings.local.json`, не коммитится |

Глобально:

```bash
claude plugin install questions --marketplace jabenb/claude-questions-pane --scope user
```

В один проект (запускать в папке проекта):

```bash
claude plugin install questions --marketplace jabenb/claude-questions-pane --scope project
```

Ставь `webhub` в тот же scope или шире: мод работает только там, где работает и хаб.

Если мод уже загружается из папки (`--plugin-dir` или `CLAUDE_CODE_PLUGIN_DIRS`), сначала убери это, иначе он загрузится дважды.

## Язык

Страница следует языку и теме, выбранным в хабе (английский, русский или украинский; светлая или тёмная). Сообщение с ответами, которое страница отправляет Claude, по умолчанию на английском: при установке спрашивается опция `language` (`en` или `ru`); поменять её потом можно в `/config` или в `/plugin`.

## Как пользоваться

- Попроси Claude подготовить вопросы, например «посмотри фичу и подготовь вопросы». Вместо списка Claude вызовет тул мода `ask`; в его результате будет адрес страницы.
- `/questions` выводит адрес страницы этой сессии. Ещё она есть на главной хаба, под названием сессии. Если сессия работает на другой машине, пробрось порт хаба (см. README webhub).
- Слева пачки с прогрессом, в центре вопросы, справа «К отправке» — ровно то, что получит Claude. Есть фильтр по статусу (ответить, готовы, у Claude, решены) и поиск.
- У каждого вопроса своё поле; готовые варианты — кнопки (повторное нажатие снимает выбор). Черновик сохраняется по ходу набора.
- **Отправить** отправляет одну пачку, **Отправить все ответы** — все вопросы с ответом. Каждый ответ цитируется под своим вопросом с id вида `[2.1]`.
- Claude отвечает на каждый id тулом `reply`: решён, или снова открыт, если он переспрашивает. Уточнение приходит со своими готовыми вариантами вместо старых. **Решено** и **Открыть снова** меняют статус вручную.
- **Копировать** кладёт пачку в буфер: все вопросы с перепиской, ещё предлагаемые варианты и неотправленные черновики.
- **Скрыть** убирает пачку со страницы, **Убрать решённые** убирает пачки, где всё решено. Чат ни то, ни другое не трогает.
- Клавиши: `J` / `K` — между вопросами, `1`–`9` — выбрать вариант, `Enter` — писать ответ, `Esc` — выйти из поля, `/` — поиск, `Ctrl+Enter` — отправить пачку.

## Как хранятся вопросы

У каждой сессии свой файл, `~/.claude/mods-data/questions/<id сессии>.jsonl` (внутри `$CLAUDE_CONFIG_DIR`, если он задан): одна строка на каждое изменение. Поэтому после перезапуска или `--resume` страница возвращается такой, какой ты её оставил, вместе с черновиками, скрытыми пачками и статусами, изменёнными вручную. Когда файл разрастается, он переписывается одним снимком.

- **Форк.** Всё, что мод оставляет в чате (результаты `ask` и `reply` у Claude, сообщение с ответами), заканчивается короткой меткой вида `‹q:1a2b3c4d#7›`: чей это файл и до какого шага он дошёл. Форк находит последнюю метку в скопированной истории и начинает с файла родителя в этой точке, поэтому не подхватывает то, что родитель сделал уже после форка.
- **Старые сессии.** Сессия, у которой ещё нет файла (из версий до этой или с потерянным файлом), при следующем старте собирается из истории чата и тогда же получает свой файл. Черновики, скрытые пачки и ручные статусы у таких сессий нигде не записывались, поэтому они не вернутся.
- **Чистка.** Раз в сутки мод удаляет файлы сессий, чей чат Claude Code уже удалил (он хранит чаты `cleanupPeriodDays`, по умолчанию 30 дней) и которые не менялись 30 дней.

## Удаление

```
/plugin uninstall questions
```
