# Панель вопросов для Claude Code

[English](README.md) | Русский

Когда Claude нужно, чтобы ты решил несколько вещей (открытые моменты фичи, варианты реализации, уточнения), он обычно пишет их нумерованным списком. Ты отвечаешь «1 — да, 3 — потом» и теряешь связь: какой ответ к какому вопросу и что Claude на него сказал.

Этот мод выносит вопросы в боковую панель. Claude выкладывает их туда, ты отвечаешь на каждый в своём поле или готовым вариантом, а панель отправляет все ответы одним сообщением, каждый под своим вопросом. Claude отвечает на каждый ответ, и его реплика появляется под этим вопросом с отметкой «решён» или «ещё открыт».

## Установка

В терминальной сессии Claude Code:

```
/plugin install questions --marketplace jabenb/claude-questions-pane
```

Ответь `y`, чтобы добавить маркетплейс, затем выбери scope (см. ниже).

Из shell:

```bash
claude plugin install questions --marketplace jabenb/claude-questions-pane
```

В десктоп-приложении Claude: нажми **+** рядом с полем ввода, затем **Plugins**, **Add marketplace** с `jabenb/claude-questions-pane`, затем **Add plugin**.

### Глобально или в один проект

Scope определяет, где работает мод:

| Scope | Где работает | Куда записывается |
|---|---|---|
| `user` (по умолчанию) | во всех проектах | `~/.claude/settings.json` |
| `project` | в этом репозитории, у всех, кто его клонирует | `<проект>/.claude/settings.json`, коммитится |
| `local` | в этом репозитории, только у тебя | `<проект>/.claude/settings.local.json`, не коммитится |

Глобально:

```bash
claude plugin install questions --marketplace jabenb/claude-questions-pane --scope user
```

В один проект (запускать в папке проекта):

```bash
claude plugin install questions --marketplace jabenb/claude-questions-pane --scope project
```

Если мод уже загружается из папки (`--plugin-dir` или `CLAUDE_CODE_PLUGIN_DIRS`), сначала убери это, иначе он загрузится дважды.

## Язык

По умолчанию панель и сообщение с ответами на английском. При установке спрашивается опция `language` (`en` или `ru`); поменять её потом можно в `/config` или в `/plugin`.

## Как пользоваться

- Попроси Claude подготовить вопросы, например «посмотри фичу и подготовь вопросы». Вместо списка Claude вызовет тул панели `ask`, и панель откроется.
- Открыть панель в любой момент: `/questions` или кнопка ❓ внизу.
- У каждого вопроса своё поле; готовые варианты — кнопки (повторное нажатие снимает выбор). Набранное сохраняется, когда уходишь из поля.
- **Отправить** отправляет один батч, **Отправить все ответы** — все вопросы с ответом. Каждый ответ цитируется под своим вопросом с id вида `[2.1]`.
- Claude отвечает на каждый id тулом `reply`: ✓ решён, или снова открыт, если он переспрашивает. Уточнение приходит со своими готовыми вариантами вместо старых кнопок вопроса. **↺ переоткрыть** и **✓ решено** меняют статус вручную.
- **⧉** рядом с батчем копирует весь батч, рядом с вопросом — этот вопрос: текст, всю переписку под ним, ещё предлагаемые варианты и неотправленный черновик.
- **Скрыть** убирает батч из панели, **Убрать решённые** убирает батчи, где всё решено. Чат ни то, ни другое не трогает.

## Как хранятся вопросы

Панель живёт в памяти сессии. Когда сессия стартует с пустой панелью (перезапуск, `--resume` или форк), мод собирает её заново из истории чата: вопросы Claude, отправленные ответы и реплики Claude. После перезапуска не сохраняются: неотправленные черновики, свёрнутые батчи, скрытые батчи (они возвращаются) и статусы, изменённые вручную. Хранение по сессиям, которое сохраняет всё это, запланировано в следующей версии.

## Удаление

```
/plugin uninstall questions
```
